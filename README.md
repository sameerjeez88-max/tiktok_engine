# TikTok Automation Engine

A Python-based automation and multi-account scheduling system featuring a local Flask web dashboard and secure browser session management.

## Features
- **Multi-Account Management:** Organize and manage multiple TikTok account workspaces.
- **Flask Web Dashboard:** Easy-to-use local interface to configure posting intervals and upload queues.
- **Automated Engine:** Safe execution handling using automated browser sessions.

## Project Structure
- `app.py`: Flask web dashboard controller.
- `engine.py`: Core automation and video scheduling logic.
- `run_system.bat`: Quick batch launcher for the system.
